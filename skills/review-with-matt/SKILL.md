`/review-with-matt <jira-url> <mr-url> [<путь к правилам>]`

Рабочая папка — `.tmp-review/`. `SKILL_DIR` — папка этого файла. Независимые вызовы — в одном сообщении.

## 1. Ground

**Спека.** Ключ тикета — из ссылки (`…/browse/ABC-123` → `ABC-123`).

```
jira issue view <KEY> --plain < /dev/null
```

Блок между `Description` и следующим `----` → `.tmp-review/spec.md`. Описание пустое → файл не создавай.

**Треды.**

```
python3 "SKILL_DIR/../audit-reply/scripts/fetch_mr.py" --url <MR> --all > .tmp-review/threads.json
python3 "SKILL_DIR/../audit-reply/scripts/read_threads.py" .tmp-review/threads.json   # индекс T1..Tn
```

## 2. Review

Запусти `/mattpocock-skills:code-review staged`. Спека — `.tmp-review/spec.md`; стандарты — путь из аргумента, если передан. Субагентов запускай с `model: "opus"`.

## 3. Threads

Прочитай тела тредов на файлах из находок и всех тредов без файла, одним вызовом:

```
python3 "SKILL_DIR/../audit-reply/scripts/read_threads.py" .tmp-review/threads.json 3 7 12
```

Находка совпадает с тредом, если у них один файл и одна суть. Номер строки может отличаться: после правок код сдвигается. У треда без файла сравнивай только суть.

Статус совпавшего треда — по смыслу реплик. Поле `resolved` — только подсказка: тред часто не закрывают, даже когда договорились.

- **принято** — автор MR согласился или сообщил о правке, и никто не возразил после этого;
- **отклонено** — автор MR объяснил, почему не правит, и никто не возразил после этого. «Так задумано» без причины не закрывает ничего;
- **открыто** — всё остальное.

- отклонено, или принято и проблемы в коде нет → секция «Снято в MR»: ссылка + причина с цитатой;
- принято, проблема в коде есть → находка остаётся, пометка «согласились в <ссылка>, но не поправлено»;
- открыто → находка остаётся, пометка «уже в треде <ссылка>».

Ссылка на тред — `<MR>#note_<note из индекса>`.

Готово, когда у каждой находки есть цитата из текущего файла или из `spec.md`; без цитаты — убери.

## 4. Publish

Скилл публикует сам — это явная просьба в смысле правила «post only when the user explicitly asks».

- Находка без треда → новый тред `файл:строка`:
  `python3 "SKILL_DIR/../mr-ready/scripts/mr_post.py" thread --url <MR> --file <path> --line <n> --body-file <md>`
- Находка «уже в треде» / «согласились, но не поправлено» → ответ в тот же тред; закрытый тред — с `--reopen`:
  `python3 "SKILL_DIR/../mr-ready/scripts/mr_post.py" reply --url <MR> --discussion <id> [--reopen] --body-file <md>`

Находок не осталось → напиши: «публиковать нечего, MR можно аппрувить».
