# Проверки для особых диффов

Читай, только когда дифф попадает под строку ниже. Кандидата — в общий вопрос шага 0, в
`checks.txt` — после ответа.

- **Своя поведенческая проверка** (скрипт, curl, прогон в образе) — до вопроса прогони её на базе и на
  HEAD: красная на базе и зелёная на HEAD, иначе она не ловит то, что чинит дифф.
- **Репо конфигов GitLab CI без своих проверок** — `ruby SKILL_DIR/scripts/ci_shellcheck.rb [--severity warning] <yml из диффа>`
  и уровень гейта в вопрос. `no-tests` не спрашиваешь: тест скрипта CI — прогон блока в образе джоба
  под режимом раннера (audit-reply, «Тест»).
- **Конфиг стороннего бинаря** (nginx, haproxy, prometheus…) — проверка этим же бинарём из образа, где
  конфиг работает. Конфиг в ConfigMap — строка на ключ из диффа:
  `python3 SKILL_DIR/scripts/configmap_test.py <configmap.yaml> <key> <путь в контейнере> <image> <команда проверки>`;
  путь и `image` — из workload'а, который монтирует ConfigMap.
