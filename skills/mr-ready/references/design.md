# Макет из Figma

Читай, когда у MR есть ссылки Figma (вызов, `/goal`, ТЗ).

## Эталон

Эталон — фрейм или страница компонентов файла: узлы-компоненты с вариантами. Экраны флоу — контекст;
для элемента без своего компонента эталон — экран. Фрейм компонентов не найден → в общий вопрос шага 0:
ссылка на него.

## Узлы

Узел-страница (`original_width` > 2000) мельчит элементы — нужны узлы компонентов. Ищешь по порядку:
ссылки `node-id` в `spec.md` → `get_design_context` по странице → `get_metadata` по странице (сотни КБ:
разбираешь скриптом из сохранённого файла, в контекст — только фреймы). Узлов так и нет → в вопрос:
ссылки на узлы компонентов.

## Снимки

Снимаешь сам, один раз: `get_screenshot` по узлу, PNG по `image_url` из ответа:
`curl -sL -o <абсолютный путь в MR_DIR/design>.png -w '%{http_code}' <url>` из корня репо: `state.py` и
`run_checks.py` падают, если cwd внутри `.git`. Пока картинка рендерится, URL отдаёт `202` и пустое тело:
повторяй раз в 5 с, пока `file` не скажет `PNG`, до 5 раз. Файл уже есть (продолжение) — оставляешь.

- Компоненты — `MR_DIR/design/components/<node>_<имя>.png` и опись `MR_DIR/design/components/INDEX.md`,
  строка на узел: `node · имя · что это (вариант, mobile/desktop) · файл`.
- Экраны — `MR_DIR/design/<node>.png`.

Готово, когда на каждый компонент и состояние, которое рисует дифф (выбран / не выбран / недоступен,
скелетон, мобайл / десктоп), есть PNG, где элемент читается.
